# Manual native body-boundary fixture

These scripts observe a disposable Claude 2.1.302 session. They are not the product FIFO, a native admission gate or a default Cargo test target. See the [current native acceptance guide](../../../../docs/guides/native-acceptance.md) for supported verification.

`prepare.py` requires an explicit already authenticated disposable `host-config` profile, native executable and built `native_acceptance` identity helper. It snapshots configuration only, stows the retained fixture's known integration, preserves other settings and adds one static FileChanged command hook. It never copies credentials. `terminal.py` uses pyte to answer normal terminal queries. Accept ordinary host trust in the native UI. `control.py` operates only that fixture's bounded local PTY controller and records its original kernel owner.

Immutable payload files and `control.json` are manual driver inputs. No script advances an AgentChat application cursor, ACK or read receipt. `hook.py` logs actual read/output/failure stages, checks the exact session and original owner, and supplies full stderr only on the selected exit-2 route. `observe.js` records native prompt results and selected model events; it is instrumentation, not a validated product control module. In particular, native interruption can abort its process-based logger. `approval.py` retains the failing abort predicate from the actual case; do not loosen it to relabel that run passing.

After every native process is terminal, `restore.py ROOT --reason TEXT` checks for unexpected configuration edits, retains postimages, restores exact original configuration and the stowed integration, and stops the owned controller. Inspect unexpected differences before changing the allowed native-counter paths. `verify.py ROOT` verifies only the selected existing records without starting another model. Its report explicitly keeps incomplete and failed control cells.

`prepare.py --module PATH` selects an explicit alternative observation module. `append.js` tests passive `session.append` user rows; `append_verify.py ROOT` compares whole results, the owned native transcript, idle observation and a later ordinary continuation. `submit.js` retains the failed direct `prompt.submit` candidate: actual 2.1.302 refuses that call from an active FileChanged hook. Do not defer/detach the call to evade the host's guard or relabel this as queued acceptance.
