# CLI banner

The committed Small Slant ASCII artwork is generated by the fixed Standards engine:

```sh
python3 standards/launcher.py banner agentchat.rs --output crates/agentchat-cli/assets/banner.txt
```

Normal builds and runtime embed only the resulting text and do not invoke a font renderer. Keep normalized ASCII and one final newline; root help/version use the shared CraftGuild presentation functions. See [NOTICE.md](NOTICE.md) for font attribution and retained terms.
